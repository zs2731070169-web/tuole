# task-tags 规格（ADDED）

## ADDED Requirements

### Requirement: 任务标签

任务可携带任意个标签（`Task.tags: string[]`，默认空数组）。标签是纯展示性元数据：不参与状态机派生、筛选、搜索匹配与统计口径。

#### Scenario: 编辑抽屉添加标签

- **WHEN** 用户在标签输入框输入「工作」并回车，再输入「复盘,学习」并回车，点「保存」
- **THEN** 任务落库 `tags: ["工作", "复盘", "学习"]`；X/遮罩关闭则全部丢弃

#### Scenario: 粘贴含分隔符文本一次多项

- **WHEN** 输入内容含半/全角逗号、顿号、分号、竖线或换行（如「a、b；c」）
- **THEN** 按分隔符切分为多个标签，逐项 trim、去空、按序去重

#### Scenario: 存储载入归一

- **WHEN** 持久化数据里 tags 缺失、非数组、或含非字符串元素
- **THEN** 载入后为合法 string[]（坏元素丢弃、缺失为 []，远古合法标签保留）

#### Scenario: Excel 往返

- **WHEN** 导出任务到 xlsx 再导入（合并或更新匹配）
- **THEN** 「标签」列以顿号连接导出、按分隔符解析导入，标签不丢失、不重复

#### Scenario: 任务卡展示

- **WHEN** 任务有标签且在工作台渲染
- **THEN** 元信息行（优先级标记之后）展示 muted 样式标签 chip；日历格 chip 不展示标签

### Requirement: 「子任务」产品词汇改为「待办项」

功能、数据契约（`Task.subtasks`）、交互（编辑抽屉管增改删、任务行面板管勾选）全部不变；仅用户可见文案更名（含 Excel 表与列头，en: To-dos）。旧导出文件的「子任务」sheet/列头仍可导入。

#### Scenario: 旧文件兼容

- **WHEN** 导入含「子任务」sheet 或「子任务」列的历史导出文件
- **THEN** 待办项内容与完成状态照常读入

### Requirement: 编辑抽屉字段顺序

字段顺序为：标题 → 分组 → 标签 → 待办项 → 优先级 → 执行时间 → 备注（长文本备注沉底；分组字段由 task-group-field 变更加入，本条为归档时修正后的现行口径）。

#### Scenario: 顺序验证

- **WHEN** 打开新建/编辑抽屉
- **THEN** 「待办项」位于「备注」之前
