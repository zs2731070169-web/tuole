# 概览洞察面板 + 任务列表折叠降权

## Why

概览统计区目前只有「数量」单一维度（总体进度 + 6 格指标 + 近30天完成节奏），而下方的全量任务列表属低频浏览（工作台/日历承担日常操作），却占据首屏主要空间。用户决策（2026-10）：概览转向多维度指标统计仪表盘，四个维度组全量采纳；列表折叠降权，首屏留给统计区。

## What Changes

### 1. 新增滚动流「洞察面板」（InsightsPanel）

位置在固定头部占位层之下、折叠列表之上，与 StatsCard 同款卡片风格，内部 2/3 列响应式网格，六个指标块：

呈现形式（2026-10 用户决策：更强图形化）与图表色彩（已经 dataviz 校验器验证）：

| 块 | 呈现 | 口径 |
|---|---|---|
| 按期完成率 | **环形图**（fill `status-done`、track `muted`，中心大号百分比）+ 副行 按时 N / 共 M | 完成日 ≤ `scheduleEnd(task)`；基准缺失（无安排日的已完成任务，历史/导入数据）不计入分母 |
| 积压健康 | **横向分桶条形图**（逾期账龄三行，ordinal 色阶 `status-overdue/55·78·100`，4px 数据端圆角、值标条尾）+ 最长逾期 N 天 + 未安排积压 M 条 | 账龄 = 今天 − 执行期结束日（≥1），桶 = 1–3 / 4–7 / ≥8 天；未安排积压 = 停靠（parkedDate ?? createdAt 日期）超过 7 天的未安排任务 |
| 未来 7 天负载 | **迷你柱状图**（今天起含今天共 7 天，`status-today/70`、今天实心 + 描环 + 值直标） | 每日计数 = 活动任务执行期覆盖该日（`scheduledOnDay`）；n>0 才挂组件 Tooltip（与节奏图同款） |
| 本周环比 | **双柱对比**（上周 `status-done/55` 弱化、本周 `status-done`，柱顶值直标 + 期名脚标）+ ±x% | 周窗口周一起算；上周为 0 → 环比显示「—」；差为 0 → 「持平」 |
| 近30天新建 vs 完成 | 数字组（新建 N · 完成 M · 净 ±K） | 窗口与节奏图同口径（近30天含今天）；净 = 新建 − 完成，正数（积压增长）用 overdue 色弱提示 |
| 未结优先级分布 | **单行分段条**（2px 表面缝隙）+ swatch/名称/计数标签行 | 未结 = 无 completedAt；高/中/低用 priority token、「无」用 muted；纯展示不可点 |

图表规范结论（dataviz 校验器）：

- 逾期 ordinal 阶 `overdue/55·78·100`：明暗双模全项 PASS（单调亮度、ΔL≥0.06、浅端对比 ≥2:1、单色相）。
- 优先级三 token：CVD 分离与常态视觉底线均 PASS；低档色度 0.049 低于地板、浅色对比 2.45/2.55 属系统既有 token（全 app 一致，不可只改图表）——以「swatch + 名称 + 计数」次级编码承接，分段条身份不依赖颜色单独成立。
- 双柱弱化档 `done/55` 浅色 1.81:1 低于 3:1 → 两柱均直接数值标注（relief 通道）。
- 文本一律文本 token（数值/标签/脚标），数据色只上 mark；环形中心百分比用比例数字（勿 tabular-nums）。

### 2. 任务列表折叠降权

- 默认折叠：一行「任务列表（N）」+「查看全部任务」按钮；展开后渲染既有 AllListView（列表 + 分页条 + 拖拽滚动全保留），按钮变「收起」。
- 状态筛选 / 优先级 / 搜索 / 日期范围任一条件变化 → 自动展开（首次挂载不触发）；筛选、搜索、Excel 导出入口全部保留。
- 无任务：不渲染折叠行，维持 EmptyState。折叠态不持久化（每次进概览默认折叠）。

### 3. 统计派生逻辑抽取

`StatsCard` 内联的 stats 计算与全部新指标合并为 `src/shared/overviewStats.ts` 纯函数 `computeOverviewStats(views, now)`（单一真相源），`routes/index.tsx` 单点 useMemo 计算、 StatsCard / InsightsPanel 消费；`tests/overviewStats.test.ts` 覆盖各口径与边界。

## 不改动 / 红线

- **固定头部结构不变**：StatsCard（含近30天节奏图）+ 状态筛选栏 + 工具行仍在 fixed 头部——新指标全部放滚动流，固定区高度不膨胀。
- **StatsCard 纯只读红线**：洞察面板同样零筛选交互，切视角唯一入口仍是状态筛选栏；优先级分布分段条纯展示不可点。
- StatsCard 六格指标、总体进度行、节奏图渲染不变（仅数据来源改为 shared 函数）。
- 概览仍为纯查看视图（TaskItem readOnly）。

## 迭代 2（2026-10 同日用户反馈，截图驱动）

1. **状态筛选栏 + ViewToolbar 整体移出概览**（用户指定移除两处）：概览无任何筛选控件——`filtered` 的 all 分支直接返回全量 `views`（忽略其他视图遗留条件，防隐性过滤）；搜索/筛选/刷新/Excel 入口只在日历与工作台；StatusFilterBar 仅日历渲染，`countViews` 只服务日历口径。固定头部只剩 StatsCard。
2. **洞察卡拆左中右三部分**：每列 = 组标题（左缘 2px 语义色条 + 加粗短标题）+ 上下两块（列间 hairline、列内块间 border-t；窄屏退化单列堆叠）。分组：左「完成表现」= 按期完成率 + 本周 vs 上周；中「积压与结构」= 逾期账龄 + 未结优先级分布；右「负载与流量」= 未来 7 天负载 + 近 30 天新建 vs 完成。
3. **连带清理**：折叠列表的「筛选变化自动展开」逻辑随筛选控件一起移除（概览内已无触发源）；列表恒为全量任务。
